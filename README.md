# Royal Haven Hotel

A premium luxury hotel management website built with PHP, MySQL, HTML, CSS and JavaScript.

## About Project

Royal Haven Hotel is a modern luxury hotel website designed to provide an elegant online experience for guests. It includes a beautiful frontend, booking system and admin dashboard for hotel management.

## Features

- Luxury hotel homepage design
- Responsive design for desktop and mobile
- Room listing and management
- Online booking system
- Admin dashboard
- Booking status management
- Dynamic gallery system
- Contact message management
- Premium animations and effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap
- Font Awesome

## Admin Features

- Admin login system
- Manage rooms
- Manage bookings
- Update booking status
- Manage gallery content

## Database

The project uses MySQL database for storing:

- Rooms
- Bookings
- Gallery images
- Contact messages
- Admin users
